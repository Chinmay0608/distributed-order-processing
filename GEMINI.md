# Project Guidelines & Integrated Skills

This repository integrates three specialized skillsets:

## 1. Graphify (`graphify`)
- Knowledge graph available at `graphify-out/` (588 nodes, 1181 edges, 21 communities).
- Before answering architecture questions, use `graphify query "<question>"`, `graphify path "<A>" "<B>"`, or `graphify explain "<concept>"`.
- Interactive visual architecture map available at `graphify-out/graph.html`.

## 2. Ponytail (`ponytail`)
- Channel senior developer minimalism: YAGNI first, standard library over custom bloat, native platform features over external packages.
- Zero speculative abstractions or dead configuration files.

## 3. UI/UX Pro Max (`ui-ux-pro-max`)
- Elite frontend aesthetic standards: 60-30-10 color balance, micro-animations, accessible contrast (WCAG), tactile feedback, and tabular numeric alignments.
- Pure modern CSS execution without heavy dependency bloat.
