## UI/UX Pro Max Rules

- Maintain visual hierarchy: 60-30-10 color balance, 4px/8px spacing rhythm, distinct typographic contrast.
- State completeness: Explicit styling for Default, Hover, Active/Focus, Disabled, and Loading states.
- Micro-interactions: Subtle transitions (`150ms ease`), interactive tactile feedback on buttons (`transform: scale(0.98)`).
- Tabular figures: Monospace/tabular digits on prices, stock counters, order IDs, and timestamps.
- Zero-Bloat: Deliver premium UI design with native modern CSS rather than adding heavy framework dependencies.
