## Ponytail Rules

- Stop at the first rung that holds: YAGNI -> existing codebase code -> stdlib -> native platform features -> existing dependencies -> one line -> minimum code that works.
- Never add unrequested abstractions: no single-implementation interfaces, no speculative factories, no unnecessary dependencies.
- Deletion over addition. Boring, maintainable code over clever tricks.
